# Окно в Rive

Иллюминатор собран в редакторе Rive (файл «Travel Animation» в аккаунте) через Rive MCP. `project/` — тот же файл, скачанный Rive CLI (`rive create --from-remote-file`): сцена `scene.rml`, скрипт и ассеты. Из него собирается `.riv` (`rive/project/build/project.riv`), команды в корневом README. На сайте Rive-версия не используется: там то же окно нарисовано кодом, оно в сотню раз легче. Rive MCP умеет только использовать ассеты, которые уже есть в файле, поэтому SVG и PNG сначала перетаскивали в панель Assets редактора.

Порядок снизу вверх: небо и облака, крыло (оба под маской стекла), ободок, шторка, рама.

Что собирается в Rive заново, а не импортируется:
- небо: вертикальный градиент `#4596F0 0%`, `#4C9DF6 7%`, `#62AEF8 45%`, `#86C1FA 66%`, `#B9DBFC 78%`, `#DCEDFD 88%`, `#EDF5FE 100%`;
- облака: два слоя, уходят влево и бесшовно повторяются, ближний 22 px/с, дальний 8 px/с (единицы стекла Figma);
- покачивание крыла: поворот до −0.45° вокруг точки (105 %, 70 %) крыла, 4.8 с туда и обратно, ease-in-out;
- тень рамы: y 0.763, размытие σ 2.479, `#4D3D38` 42 %;
- внутренняя тень шторки у ободка: в `shade.svg` она сделана SVG-фильтром, Rive его не импортирует.

## Как собрано в Rive

Артборд «Plane window» 125.856 × 164: окно 109.856 × 148 плюс поле 8 px со всех сторон, чтобы тень рамы не обрезалась по краю артборда. State machine «Plane window» при старте уходит в зацикленный таймлайн «Flight», пока она играет, скрипт двигает облака и крыло.

Слои сверху вниз:

| Слой | Что это | Позиция на артборде |
| --- | --- | --- |
| Рама | `frame.svg` | 8.653, 9.602 (начало SVG) |
| Шторка | `shade.svg`; кольца «Тень у ободка» пересобраны: внешний прямоугольник по часовой, контур против часовой и с флагом isHole (без него Rive не вычитает контур и тень ложится на всю шторку), заливка clockwise, 42 % / 30 %, feather 6.12 / 1.66 (2σ) | 20.866, 24.613 |
| Ободок | `rim.svg` | 20.866, 24.613 |
| PlaneGlass | скрипт `project/PlaneGlass.luau`: небо, облака, крыло, обрезка по стеклу; вход `speed` (1 = как на сайте) | 27.884, 33.175 |
| Тень рамы | внешний контур рамы, `#4D3D38` 42 %, feather 4.96, y +0.763, заливка clockwise | под рамой |

Rive при импорте SVG теряет прозрачность у `rgba()`-заливок и не знает SVG-фильтров, поэтому тени сделаны заново. Кириллические имена слоёв из `frame.svg` и `rim.svg` приходят в виде кракозябр (в файлах они закодированы байтами) и переименованы обратно.

### Шторка в начале

Как на mikes.cv: при старте шторка закрыта и поднимается в обычное положение. Тайминг взят из кода сайта: подъём 900 мс по easeInOutCubic (`cubic-bezier(0.65, 0, 0.35, 1)`), ход 171 из 300 px окна сайта, у нас 95.83 единицы ободка. Перед подъёмом шторка 0.3 с стоит закрытой. Таймлайн «Intro» (72 кадра при 60 fps, один раз) двигает по y панель, бортик, ручку, кромки и контур `shade-panel`, которым обрезана внутренняя тень. Сама тень остаётся на месте, как у сайта. Панель и `shade-panel` удлинены вверх до y −100, чтобы закрытая шторка перекрывала всё окно. На сайте закрытая шторка темнеет (`brightness(1 − shade × 0.82)`), у нас яркость не меняется.

State machine «Plane window»: слой «Полёт» (Entry → Flight, цикл) и слой «Шторка» (Entry → Intro, один раз) играют одновременно.
