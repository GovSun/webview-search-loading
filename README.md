# Поиск авиабилетов: экран загрузки (webview)

Экран из Figma «Экскурсии» → «Редактировать поиск» (node `903:119485`), 360 × 800, на React 18 + Vite + TypeScript, стили в CSS Modules, токены DS Mtravel 2.0 с именами из Figma (`src/styles/tokens.css`).

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/
npm run build:single   # dist-single/index.html, всё в одном файле
```

Живая версия: https://govsun.github.io/webview-search-loading/

Каждый пуш в `main` собирает `dist/` и публикует его на GitHub Pages (`.github/workflows/pages.yml`, в настройках репозитория Pages → Source: GitHub Actions). Пути в сборке относительные, поэтому сайт работает по адресу `https://<user>.github.io/<repo>/`.

На телефоне экран занимает весь viewport, как в webview. В браузере на десктопе он показан в рамке 360 × 800 со статус-баром из макета: рамка нужна только для сверки, статус-бар в приложении нативный.

| `components/PlaneWindow` | Иллюминатор: рама и ободок (SVG из Figma с округлым контуром), стекло с небом и облаками на Canvas 2D (`cloudSky.ts`), крыло (`assets/window/wing.webp`), шторка с подъёмом при открытии (`Shade.tsx`) |
| `rive/project` | То же окно в Rive (на сайте не используется): проект Rive CLI, скачанный из файла «Travel Animation» (сцена `scene.rml`, скрипт неба и облаков `PlaneGlass.luau`, SVG рамы, ободка, шторки, крыло). Подробно в `rive/README.md` |

## Иллюминатор

Всё окно нарисовано кодом и весит около 12 КБ по сети: код окна около 4 КБ (gzip), крыло 5 КБ (WebP), рама 1.2 КБ, ободок и маска стекла встроены в бандл. Отдельного рантайма нет.

- **Небо и облака** рисуются на Canvas 2D (`cloudSky.ts`): дневной градиент и два слоя облаков, которые уходят влево и бесшовно повторяются. Ближний слой 33, дальний 12 px/с в единицах стекла Figma (ближние облака проходят окно примерно за 2 с), меняются в `speed` у `FRONT` и `BACK`. Кадр рисуется примерно за 0.1 мс. Облака стоят на паузе, когда окно вне экрана или вкладка либо webview в фоне. Плотность canvas = `devicePixelRatio` × масштаб окна, максимум 4.
- **Крыло** взято из стоковой иллюстрации в Figma (фрейм «21414987_Airplane_window (1) 1», `948:62116`, слои 16–126 группы `group-R5`), выгружено картинкой 4× и переведено из лавандового в серый `scripts/gray-wing.py`. WebP весит 5 КБ вместо 21 КБ у PNG, на глаз разницы нет. Крыло медленно ходит вверх и вниз, по 3.5 с в каждую сторону: всё крыло сдвигается на 1.6 единицы, а кончик за счёт поворота у корня ещё немного дальше, как пружинящее в полёте крыло.
- **Шторка** (`Shade.tsx`) повторяет mikes.cv: при открытии экрана она закрыта, 0.3 с стоит и за 0.9 с поднимается по easeInOutCubic (длительность и кривая взяты из кода сайта), потом остаётся приспущенной. Ход 95.83 единицы ободка, это 171 из 300 px окна сайта. Внутренняя тень у ободка стоит на месте, шторка едет над ней. На сайте закрытая шторка темнеет почти до чёрного, у нас цвет не меняется.
- **Рама** со своей тенью: тень из Figma (y 0.763, σ 2.479, `#4D3D38` 42 %) рисует CSS `drop-shadow` на `<img>`, а не SVG-фильтр в `frame.svg`, иначе в WebKit она обрезалась и пикселила.
- При `prefers-reduced-motion: reduce` ничего не движется: облака стоят, крыло не качается, шторка сразу открыта.
- Окно в 1.2 раза крупнее, чем в Figma: размеры в `PlaneWindow.module.css` заданы в `--u` (один пиксель Figma), `--u: 1.2px`. Облака подстраиваются под размер сами.

То же окно собрано в Rive (`rive/project`, подробно в `rive/README.md`). На сайте его нет: рантайм Rive весит около 1.1 МБ (WebAssembly 980 КБ и JS 89 КБ в gzip), а файл с бесплатного плана начинается с заставки Rive. Rive-версия пригодится для нативного приложения или если анимацию будут править дизайнеры. Собрать `.riv`:

```bash
~/.rive/bin/rive pull rive/project            # забрать правки файла «Travel Animation» из редактора
~/.rive/bin/rive rive/project --publish       # подписанный .riv в rive/project/build (нужен rive login)
```

## Шрифт

Inter Mbank (400 / 500 / 600) сабсетнут до латиницы, кириллицы и знаков (`src/assets/fonts`, по ~21 КБ на начертание). Это версия Inter (The Inter Project Authors) под SIL Open Font License 1.1, копирайт и текст лицензии лежат в метаданных каждого файла. Если в приложении шрифт уже подключён нативно, `styles/fonts.css` можно убрать.
