# Поиск авиабилетов: экран загрузки (webview)

Экран из Figma «Экскурсии» → «Редактировать поиск» (node `903:119485`), 360 × 800, на React 18 + Vite + TypeScript, стили в CSS Modules, токены DS Mtravel 2.0 с именами из Figma (`src/styles/tokens.css`).

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/
npm run build:single   # dist-single/index.html, всё в одном файле
```

Живая версия: https://govsun.github.io/webview-search-loading/

Каждый пуш в `main` собирает `dist/` и публикует его на GitHub Pages (`.github/workflows/pages.yml`, в настройках репозитория Pages → Source: GitHub Actions). Пути в сборке относительные, поэтому сайт работает по адресу `https://<user>.github.io/<repo>/`.

На телефоне экран занимает весь viewport, как в webview. В браузере на десктопе он показан в рамке 360 × 800 со статус-баром из макета: рамка нужна только для сверки, статус-бар в приложении нативный.

## Небо, облака, крыло, шторка

Крыло взято из стоковой иллюстрации в Figma: фрейм «21414987_Airplane_window (1) 1» (`948:62116`) на странице «Результат поиска», слои 16–126 группы `group-R5` (обтекатели, градиенты, линии предкрылков и закрылков, без неба, облаков, луны и шторки). Слои скопированы во временный фрейм размером с проём окна (1123 × 1597) и экспортированы из Figma в PNG 280 × 399 (4× от нашего стекла), так что форма и светотень точно как в макете. Проём ложится на стекло по ширине и центрируется по высоте.

В иллюстрации крыло лавандовое, у нас оно серое: `scripts/gray-wing.py` переводит каждый пиксель в его яркость с лёгким холодным оттенком, как у серых DS (`#F2F3F5`, `#7E7F81`), и чуть осветляет верхнюю поверхность. После новой выгрузки из Figma: `python3 scripts/gray-wing.py wing-figma.png src/assets/window/wing.png` (нужен Pillow).

Облака пухлые, с плавным градиентом и тенями в складках. Время суток дневное: небо голубое, сверху взят синий `#4596F0` из Figma.

Шторка приспущена так же, как на mikes.cv в исходном положении (`translateY(-57%)`): видна только её нижняя кромка со светлым бортиком и ручкой. Форма, цвета и внутренняя тень у ободка перенесены с сайта в координаты нашего ободка. Шторка неподвижна, тянуть её нельзя.

Движение как на mikes.cv: облака уходят влево и появляются снова справа, ближний слой быстрее дальнего. Скорости я измерил на сайте по кадрам и пересчитал на наше стекло (70 px вместо 121 px): ближние облака 11 px/с (окно проходит примерно за 6 с), дальние 4 px/с. Крыло слегка покачивается: кончик уходит меньше чем на пиксель за 4.8 с, примерно как крыло в полёте. Three.js не используется.

- У стекла задан тот же градиент неба фоном, так что до первого кадра и без canvas окно не бывает пустым.
- При `prefers-reduced-motion: reduce` облака стоят, а крыло не качается: показывается один неподвижный кадр.
- Анимация ставится на паузу, когда окно вне экрана, а также когда вкладка или webview уходит в фон.
- Спрайты пересобираются при смене `devicePixelRatio`, максимум 3×.

## Шрифт

Inter Mbank (400 / 500 / 600) сабсетнут до латиницы, кириллицы и знаков (`src/assets/fonts`, по ~21 КБ на начертание). Это версия Inter (The Inter Project Authors) под SIL Open Font License 1.1, копирайт и текст лицензии лежат в метаданных каждого файла. Если в приложении шрифт уже подключён нативно, `styles/fonts.css` можно убрать.
